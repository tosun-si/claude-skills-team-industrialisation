# Prompt(s) de démo — à COLLER (jamais taper à la main)

## Prompt principal (IDENTIQUE pour la session SANS et la session AVEC)

> Le contraste ne tient que si le prompt est rigoureusement le même des deux
> côtés. Il reste **volontairement haut niveau** : il ne mentionne ni
> « hexagonal », ni « multi-stage », ni « non-root ». C'est tout l'intérêt —
> ce sont les **skills** qui injectent les conventions, pas le prompt.

```
Crée un petit service Python FastAPI « citation du jour » : un endpoint
GET /quote qui renvoie une citation aléatoire (liste en mémoire, pas de base de
données) et un GET /health. Ajoute son Dockerfile, sa CI/CD GitHub Actions et
ses tests. Puis prépare un commit et une pull request.
```

## Variante de secours (si tu veux raccourcir en live)

```
Crée un service FastAPI « citation du jour » (GET /quote aléatoire + GET /health)
avec Dockerfile, CI GitHub Actions et tests.
```
